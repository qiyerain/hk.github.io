# 博客 UI 重新设计 - 赛博科技风格

## 概述

将现有 Hexo 博客 (Anzhiyu 主题) 改造为现代科技感风格，通过配置修改 + 自定义 CSS 实现，保留所有现有功能。

## 设计目标

- **风格定位**: 现代科技感 - 深色背景、霓虹色彩、渐变效果
- **目标用户**: 技术博客读者，追求视觉冲击力和阅读体验
- **实现原则**: 不更换主题，通过配置 + 自定义 CSS 达到 85-95% 效果

## 配色方案

### 赛博蓝 (Cyber Blue)

| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主色 (Primary) | `#00d4ff` | 青蓝色，用于链接、按钮、高亮 |
| 辅色 (Secondary) | `#6366f1` | 靛紫色，用于渐变、装饰 |
| 强调色 (Accent) | `#0099ff` | 亮蓝色，用于悬停、激活状态 |
| 深色背景 | `#0a0a1a` ~ `#1a1a2e` | 渐变深蓝黑 |
| 卡片背景 | `#121220` | 带透明度的深色 |
| 文字主色 | `rgba(255,255,255,0.85)` | 亮白色 |
| 文字辅色 | `rgba(255,255,255,0.6)` | 灰白色 |
| 边框色 | `rgba(0,212,255,0.2)` | 青蓝半透明 |

### 渐变定义

```css
/* 主渐变 */
--gradient-primary: linear-gradient(135deg, #00d4ff 0%, #6366f1 100%);

/* 背景渐变 */
--gradient-bg: linear-gradient(135deg, #0a0a1a 0%, #1a1a2e 100%);

/* 卡片渐变 */
--gradient-card: linear-gradient(145deg, #121220 0%, #0d0d1a 100%);
```

## 布局改造详情

### 1. 导航栏 (Navbar)

**改造内容**:
- 透明毛玻璃效果 (backdrop-filter: blur)
- 滚动时添加深色背景
- Logo 和菜单项悬停发光效果
- 搜索按钮霓虹边框

**CSS 要点**:
```css
#nav {
  background: rgba(10, 10, 26, 0.8);
  backdrop-filter: blur(12px);
  border-bottom: 1px solid rgba(0, 212, 255, 0.1);
}

#nav a:hover {
  text-shadow: 0 0 10px #00d4ff;
}
```

### 2. 首页 Banner

**改造内容**:
- 深色渐变背景替换原图
- 站点标题发光效果
- 打字机动画保留，颜色改为青蓝
- 添加粒子/星空背景动画

**技术方案**:
- 使用 canvas 粒子库 (如 particles.js 或自定义)
- 背景 CSS 渐变 + 粒子叠加

### 3. 文章卡片

**改造内容**:
- 深色卡片背景，悬停时发光边框
- 封面图渐变遮罩
- 标题发光悬停效果
- 元信息 (日期、分类) 使用青蓝色

**CSS 要点**:
```css
.post-card {
  background: #121220;
  border: 1px solid transparent;
  transition: all 0.3s ease;
}

.post-card:hover {
  border-color: rgba(0, 212, 255, 0.5);
  box-shadow: 0 0 20px rgba(0, 212, 255, 0.2);
}
```

### 4. 文章阅读页

**改造内容**:
- 正文背景深色，文字亮色
- 代码块霓虹边框 + 增强语法高亮
- 引用块左侧青蓝色边框
- 标题装饰 (渐变下划线)
- 阅读进度条 (顶部渐变条)

**代码块样式**:
- 背景: `#0d0d1a`
- 边框: 左侧 4px 青蓝发光
- 语言标签: 渐变背景

### 5. 侧边栏

**改造内容**:
- 个人信息卡：深色背景 + 发光头像框
- 标签云：标签悬停发光
- 目录导航：当前项青蓝色高亮
- 整体透明度调整

### 6. 页脚

**改造内容**:
- 深色渐变背景
- 链接悬停发光
- 可选：底部粒子动画

## 特效配置

### 基础特效 (平衡适中强度)

| 特效 | 应用位置 | 实现方式 |
|------|----------|----------|
| 渐变色 | 按钮、标题、进度条 | CSS linear-gradient |
| 发光边框 | 卡片悬停、代码块 | box-shadow |
| 悬停动画 | 链接、按钮、卡片 | CSS transition |

### 额外特效

| 特效 | 说明 | 实现难度 |
|------|------|----------|
| 发光文字 | 标题、关键词霓虹效果 | 低 (CSS text-shadow) |
| 粒子背景 | 首页动态粒子/星空 | 中 (canvas/库) |
| 代码块美化 | 霓虹边框 + 高亮增强 | 低 (CSS) |
| 阅读进度条 | 顶部渐变进度指示 | 低 (CSS + JS) |

## 实现步骤概览

1. **配置修改** - 修改 `_config.anzhiyu.yml` 中的主题色配置
2. **自定义 CSS** - 创建 `source/css/cyber-tech.css` 注入样式
3. **粒子背景** - 添加 canvas 粒子动画脚本
4. **阅读进度条** - 添加进度条 JS 脚本
5. **代码高亮** - 配置 highlight.js 主题
6. **测试验证** - 本地预览，调整细节

## 兼容性考虑

- 深色模式切换按钮保留，手动切换时样式一致
- 移动端适配：减少特效，保证性能
- 旧浏览器降级：忽略 backdrop-filter 等高级特性

## 成功标准

1. 全站呈现统一的赛博科技风格
2. 所有区域完成视觉改造
3. 不影响现有功能 (评论、搜索、分享等)
4. 页面加载性能无明显下降
5. 移动端体验良好
