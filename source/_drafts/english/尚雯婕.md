# 一、尚雯婕方法到底是什么

她是复旦法语系出身，自学多门语言，核心叫**"十篇听写说练习法"**，本质是**模拟母语习得：用耳朵输入 → 精听到每个词 → 背到和原声同速**，而不是背单词、背语法书。

**四步循环（每一篇材料都走一遍）：**

| 步骤 | 做法 |
|---|---|
| 1. 选料 | 挑新闻、专业谈话、纪录片（语法工整、逻辑清楚）；**不选**文学、诗歌、影视剧对话；按自己水平选长度，先短后长 |
| 2. 听写 | 先盲听3-10遍抓主题 → 听一句暂停写一句 → 听不懂反复听，实在听不出再看原文，重点抓连读、弱读 |
| 3. 吃透 | 自己查字典、查语法，为什么用 for 不用 to、为什么 must 不用 have to，全部搞懂 |
| 4. 同速背诵 | 反复朗读直到脱稿，**背到和原音频一样快、一样的语调**，录下来对比 |

**她本人补充的3个关键原则：**
- 发音关先过（音标对，耳朵才听得出来），语法关同步；
- 做4-5篇就会感觉听说突飞猛进，突击2个月3-4篇也够用；
- **不要"大胆乱说"**——心态可以放松，但每句要想清楚确定是对了再说，说错的语法会固化，后面更难改。

# 二、给你的改造版：不背新闻，背你自己的面试稿

你不是要"精通英语"，而是**面试当天能脱稿、流畅、不出错地说出来**。所以把"20分钟新闻"换成你已经写好的稿子，方法内核不变（精听 → 吃透 → 同速脱稿）。

**每篇稿子走这5步（每天一篇）：**
1. **盲听**：先把这段英文放3遍，不看文字，抓大意；
2. **逐句精听**：听一句、暂停、自己跟读一遍，卡壳的词标出来；
3. **吃透**：查音标、查连读（比如 `engineering` /ˌendʒɪˈnɪrɪŋ/、`distributed`、`microservice`、`latency`），每个词读准；
4. **同速跟读**：跟着音频一句一句对齐语速和停顿，不要自己放慢拖长音；
5. **脱稿录音**：合上稿子自己说一遍并录音，回放和原句对比，错的地方重练。

# 三、14天面试突击计划（每天30-45分钟，全神贯注，不要边刷牙边听）

### 第0阶段｜第1天：先过发音关（只做这一件事）
- 把稿子里的**技术专有名词**逐个查音标、读准，做成一张自测表：

| 词 | 重点 |
|---|---|
| engineering | 重音在 neer /nɪr/，和 near 同音 |
| distributed systems | /dɪˈstrɪbjuːtɪd/，别吞音 |
| microservice ecosystem | /ˈmaɪkrəʊsɜːrvɪs/ /ˈiːkoʊsɪstəm/ |
| RAG retrieval augmentation | /rɪˈtriːvl ˌɔːɡmenˈteɪʃn/ |
| MCP protocol | /ˈproʊtəkɔːl/ |
| latency / TPS | /ˈleɪtənsi/，P99、100K TPS 读顺 |
| SOFABoot / SaaS / MQTT | 字母逐个读清楚，不要含糊带过 |

- 验收：以上单词单独抽出来，你能一次读准。

### 第1阶段｜第2-4天：自我介绍（每天一段，背到肌肉记忆）
- **第2天**：开场两句 + Professional Background（4句），脱稿；
- **第3天**：数字马力部门介绍 + 项目1 数字员工（3层记忆、MCP、12个LLM）；
- **第4天**：项目2 zfbbizriskagent（五阶段演进、三个模块）。

### 第2阶段｜第5-8天：四个项目逐个"精听+脱稿"
- **第5天**：项目3 bizriskide（P99 <100ms、100K TPS、核心pipeline）；
- **第6天**：项目4 uniaccessmng（五个模块、需求审批、告警规则）；
- **第7天**：鼎易智远整段（SaaS、Spring Cloud、MQTT、分布式事务）；
- **第8天**：教育背景 + 收尾句（bring my skills and experience to your team）。

> 每篇验收标准：**合上稿子，语速自然、不卡壳、不错时态，说完整段**，才算过。

### 第3阶段｜第9-11天：高频问答（用同一方法准备答案稿）
- **第9天**：离职原因（三年稳定、触到天花板、想进新平台）；
- **第10天**：为什么来深圳（技术先进的公司多 + 有朋友）；项目挑战STAR（单Agent→多Agent / 高并发削峰读写分离，二选一背熟）；
- **第11天**：备用句循环练熟：`Sorry, could you repeat that, please?`，以及反问、过渡句。

### 第4阶段｜第12-14天：模拟面试（输出闭环）
- **第12天**：完整自我介绍从头到尾录音一遍，挑出卡壳的3个句子重练；
- **第13天**：找人/AI扮演面试官随机提问，你用准备好的段落回答，录音；
- **第14天**：只听录音复盘，把所有说错、卡顿、时态错误列成一张清单，只攻这些点。

# 五、避坑提醒（尚雯婕本人强调过）
1. **专注**：每天30-45分钟坐下来专心听读，比散步时泛听2小时有效；
2. **先对再熟**：每句先确认语法、发音没错，再求快，别把错的说法背熟；
3. **同速是关键**：不要慢吞吞一个词一个词蹦，要练到自然语速；
4. **材料别贪难**：就用你自己的稿子，这是你面试唯一要说的内容，性价比最高。
